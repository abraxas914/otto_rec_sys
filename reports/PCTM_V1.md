# 2026 概率转移方法适配：实测与判断

日期：2026-09-20。研究依据与选型见 [前沿方法调研](MODERN_METHODS_REVIEW.md)。本轮将 PCTM 的平滑转移对数聚合适配到 OTTO，增加到现有排序器中；不是作者原始数据集上的复现，也没有训练神经网络。

## 同候选实验

固定 rank-v1 的 200 个候选、训练查询、原有 31 个特征以及三任务 LightGBM 参数。分别训练增加两个频次特征、增加六个转移证据/排名和两个频次特征的版本。重建训练特征时逐行检查原有特征与缓存完全一致；旧模型在开发集的结果与上一轮完全一致。

| 方法 | 固定开发集：18,152 会话 | 本轮新复核集：6,951 会话 |
|---|---:|---:|
| 原 rank-v1 | 0.534274 | 0.523700 |
| 仅新增频次特征 | 0.533012 | 0.523686 |
| 新增 PCTM 与频次特征 | **0.535393** | **0.525517** |
| PCTM 版本相对原模型差值 | +0.001119 | +0.001817 |
| 差值的会话 bootstrap 95% 区间 | [-0.000790, 0.003163] | [-0.001117, 0.004785] |

两个区间均跨零。当前证据是方向一致的小幅改善，不能断言稳定胜出。频次对照未产生类似增益，提示转移证据值得继续研究，但不能据此排除抽样波动。1,000 次配对会话重采样未覆盖时间、商品关联和自适应选模带来的全部不确定性。

复核集明确排除原 1% 开发样本和上一轮 6,965 个复核会话；与上一轮仍在同一周后两天，属于新会话而不是新的时间环境。不同复核集的绝对分数不能直接比较。本轮查看后，该集合也已成为已知数据。

## 提升与局限

开发集：点击多命中 16 个目标，加购多 21 个，下单持平。新复核集：点击少 4 个，加购多 1 个，下单多 4 个。样本量较小，尤其下单差别只有几个目标；不应将总分改善解释为每个行为都变好。

额外召回诊断：若不限制总预算、在原 200 候选之外加入 PCTM 前 50 项，开发集新增点击/加购/下单目标命中为 116/15/3，新复核集为 55/3/0。这是未参与排序的覆盖诊断，不是 Recall@20 提升，且候选总量增加。购买召回与现有方法重叠较多，继续投入前需要证明互补性。

## 方法边界

- 分目标行为建图；历史最后 30 个事件；正向时间差不超过一天，事件距离不超过 5。
- 转移距离衰减与历史衰减均为 0.7；tau=15000；每源商品保留 80 邻居。没有参数搜索。
- 允许历史商品和重复购买；不套用某些序列基准的已看商品过滤。
- 训练关系图截止 1660514390707；评估关系图截止 1661119190707。所有图事件严格早于对应截止时间；评估图最大时间为 1661119190607。
- 使用 10% 稳定会话样本，评估图商品数 1,190,158。候选集合未加入 PCTM 召回；特征不是校准后的业务概率。
- 两个新增模型使用相同的 120 棵树、15 叶子和训练数据。训练缓存不可跨参数复用；改变实验配置应使用新目录。JSON 的 seconds 包括当次执行和缓存复用，不代表完整冷启动成本。

## 决定

保留为候选增强版本，不因约 0.001–0.002 的点估计提升就宣布替换。下一条值得投入的路线是行为感知的强序列训练目标，以固定候选神经评分验证表示的增量，再单独测试向量召回；如果没有超越强成对转移模型，就不扩大架构和算力。

本轮没有新 Kaggle 提交。最新已验证榜单仍为 v2 Public 0.54340 / Private 0.54352；本表全部是本地分数。

## 复现

先完成 docs/RANKING_EXPERIMENT.md 与 rank-v1 数据/模型准备，再运行：

```sh
python -m otto.pctm_experiment
python -m otto.pctm_experiment --confirm
PYTHONPATH=. python scripts/compare_predictions.py --labels artifacts/pctm-v1/dev/labels.jsonl --base artifacts/pctm-v1/dev/rank_v1.csv --candidate artifacts/pctm-v1/dev/pctm_features.csv --output reports/pctm_v1_dev_uncertainty.json
PYTHONPATH=. python scripts/compare_predictions.py --labels artifacts/pctm-v1/confirm/labels.jsonl --base artifacts/pctm-v1/confirm/rank_v1.csv --candidate artifacts/pctm-v1/confirm/pctm_features.csv --output reports/pctm_v1_confirm_uncertainty.json
python -m unittest discover -s tests -v
```

结果保存在 pctm_v1_dev.json、pctm_v1_confirm.json 和对应 uncertainty 文件。26 项测试通过，新增测试覆盖平滑概率排序等价性、严格时间与重复商品、未知商品和复核集排除规则。
