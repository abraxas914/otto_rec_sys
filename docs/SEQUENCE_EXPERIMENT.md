# 行为序列模型第一轮协议

2026-09-20，在查看本轮结果前确定。目标：检验神经行为表示能否在现有相同候选上提供额外排序信息。参考 eSASRec 的强训练对照思想，但本项目是独立的小型 OTTO 适配，不能称为 eSASRec 完整复现。

## 时间隔离

神经词表、参数、训练标签全部来自 ts < 1660514390707（排序训练窗口开始前）的事件，并固定用于排序训练及开发/复核。这比在开发开始前重新训练更保守，但避免排序器接触神经模型已经背过的标签。评估时不更新神经参数。原有图仍按上一轮的各自时间边界使用。

## 数据和预算

词表取上述历史中频次最高的 200,000 个商品；其余映射未知，商品 0 是合法 ID。取早期可切分会话的 50%（seed=2701），每个会话一个严格时间边界前缀（seed=2718），点击为下一次点击，购买为剩余已知事件内唯一正商品集合。未知正商品不训练，但记录覆盖损失；评估不删除任何会话或目标。

最多 30 个历史事件；64 维向量。对照为近期权重 0.8 的池化编码器，以及两层、两头 Transformer（128 维前馈、dropout=0.1、因果注意力）。两者输入商品、行为、相对时间桶，Transformer 另加位置。三个目标行为有独立线性头，输出与商品向量作归一化点积。

固定 3 轮，batch=512，AdamW lr=0.001，weight_decay=0.0001，seed=2718。每次随机抽取一个已知正商品；负池为批内目标与 512 个均匀商品，屏蔽该任务全部已知正商品。各任务批内平均损失再等权平均，temperature=0.12。不声称这是无偏全词表 softmax；也不使用复核集选择轮次。历史商品仍可作为正商品；多个正商品不得互作负例。

## 排序与验证

保留原 rank-v1 候选与 31 特征；加入神经分数、候选内排名和商品已知标志。对照为原模型、仅已知标志、池化特征、Transformer 特征。另比较 PCTM 与 PCTM+Transformer，测已有较强特征之上的增量。树参数保持 120 棵、15 叶。

全部结果先在原固定开发集报告。冻结后使用最后两天种子 991 的 [0.30,0.45) 哈希段，排除原 1% 开发样本；之前两轮使用的 [0,0.30) 不再充当新复核集。该集合仍处于同一周，不代表时间漂移泛化。主比较为 Transformer 增强 vs rank-v1；池化对照、PCTM 组合和单独神经排名作为诊断。报告多重比较与会话 bootstrap 的局限。

模型规模与训练时长较小，失败只能否定当前预算/协议下的版本，不能否定所有序列模型。词表覆盖、冻结模型的时间陈旧与未收敛可能解释失败，必须记录。

## 运行

先按 docs/RANKING_EXPERIMENT.md 和 reports/PCTM_V1.md 完成前序缓存，随后安装 requirements-neural.txt。基础依赖不包含 PyTorch，未安装时只跳过神经测试。

```sh
pip install -r requirements-neural.txt
python -m unittest discover -s tests -v
python -m otto.sequence_experiment train
python -m otto.sequence_experiment rank
python -m otto.sequence_experiment dev
# 模型冻结后进行一次新会话复核
python -m otto.sequence_experiment confirm
```

模型和训练缓存保存在 artifacts/sequence-v1，汇总保存到 reports。默认优先使用 Apple MPS，不可用时回退 CPU。种子固定不代表不同硬件完全逐位一致。变更配置时使用新实验目录；本实验的前序缓存需来自仓库所描述的固定版本。

来源：[eSASRec 作者仓库](https://github.com/blondered/transformer_benchmark)。其原始模型、损失和数据协议并未在此逐项复现，不能把本轮结果冠以作者模型的基准成绩。

## 本机运行修正

GPU 特征生成完成后，第一次混合进程在进入 LightGBM 排序训练阶段发生原生崩溃（退出码 139）。缓存完整保留；将 CPU 排序训练与推理放入不导入 PyTorch 的独立进程后恢复正常。尚未归因到某个底层库的具体缺陷，不把排查猜测写成确定结论。数据、目标、模型参数未因此修改。
