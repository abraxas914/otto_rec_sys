# 评估与证据协议

## 比赛指标

对行为 t、会话 s，预测列表 P 先截前 20，再按商品去重。标签 G：clicks 为截断后的下一个点击商品，carts/orders 为后续该行为商品集合。

`R_t = sum_s |P_st ∩ G_st| / sum_s min(20, |G_st|)`

`Score = 0.1 R_clicks + 0.3 R_carts + 0.6 R_orders`

这是跨会话汇总分子分母，不是会话 Recall 的简单平均。无该行为标签的会话不增加该任务分母；预测缺失不能悄悄丢掉标签行。某任务总分母为零时分数不可定义，评估器拒绝输出综合分。

统一列表实验把同一 P_s 分别对三种 G_st 计算以上分项指标。比赛三榜与统一榜采用同一标签窗口，但任务设定和结果表分开。

## 时间与可用信息

- 拟定三个滚动时间区间：构建候选/基础模型、训练排序器与调参、冻结最终测试；确切边界在查看时间范围后写入配置。
- 任一训练数据事件不能超越该模型的冻结时间；跨边界会话截断。标签后缀绝不进入特征、共现和 embedding。
- 当前请求的前缀可用；冻结式评估不汇总其他未来请求的前缀。
- 比赛允许使用提供的截断测试前缀做 transductive 学习；单独标注这一实验，不与严格时间因果模式混为一谈。
- 赛后研究数据与原竞赛文件可能使用不同切分；保留来源与标签构造，不能直接比较榜单数字。
- 训练采样与候选负采样分别记录；最终评估使用完整目标窗口、真实候选生成与全量标签，不以采样负例替代检索任务。

## 其他指标

- 候选内理想 Top-20 上限：分子 `sum_s min(20, |C_st ∩ G_st|)`，分母同官方；不要让超过 20 的候选命中导致“上限”大于 1。
- 目录覆盖：评估中推荐的不同商品数 / 固定可用目录商品数；同时报告训练未见商品比例。
- 长尾曝光占比：训练期频次分位定义长尾，阈值冻结；推荐位置计数作分母。
- 新颖性：训练平滑频次的负对数，公开平滑项；新颖不自动代表相关或有用。
- 行为差异度：列表商品 embedding 余弦距离均值；只解释为行为表示差异，不声称语义/品类多样性。
- 延迟：指定硬件、并发、冷/热缓存、候选数与网络边界；训练时间不混入请求延迟。
- 分层：会话前缀长度、有无加购、训练商品热度、训练未见商品；不把匿名 session 当成可跨期追踪的用户。
- 不确定性：配对 session bootstrap，每次重算分子/分母比值；跨日稳定性另报，相关性强时采用时间块复采样作敏感性对照。

## 证据边界

| 想讨论的量 | OTTO 能否直接支持 | 本项目处理 |
|---|---|---|
| 行为 Recall、共现、重复访问 | 能 | 真实离线实验 |
| CTR/CVR | 没有完整曝光/机会分母 | 使用行为预测指标，不命名为真实 CTR/CVR |
| GMV/利润 | 没有价格/成本 | 不估算真实收益；若演示须标注合成价格 |
| 长期留存/满意度 | 无所需长期用户观测与反馈标签 | 上线实验设计或独立数据研究 |
| 品类/商家/库存/安全 | 无真实元数据 | 代理或合成约束，明确标注 |
| 推荐的因果增量 | 无随机推荐曝光与 propensity | 不直接用 OTTO 做可信 OPE |

CTR AUC 提升不蕴含线上 CTR 提升；线上 CTR 提升也不蕴含长期效用提升。加购和下单在观测窗口内不必包含先前点击，因此不能无条件使用“点击 × 条件加购 × 条件下单”的链式分解。

## 结果记录契约

每次保存 run_id、代码版本/文件哈希、数据版本/哈希、切分配置、seed、候选预算、训练预算、硬件、参数、分项指标、分子/分母、置信区间、运行成本和结论。先写待检验假设，再看结果；测试窗口不得反复用于挑选权重。
